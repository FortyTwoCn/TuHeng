# 权限矩阵

| 角色               | 数据范围                             | 能力                                     |
| ------------------ | ------------------------------------ | ---------------------------------------- |
| STUDENT            | 自己 + 已选班级发布作业              | 上传、提交、自测、错题、已发布结果、申诉 |
| TEACHER            | 明确 TeachingGrant 授权班级/本人题库 | 建题、发布、复核、发布成绩、处理申诉     |
| TEACHING_ASSISTANT | 明确授权班级                         | 查看提交、复核；成绩发布只允许教师       |
| COURSE_MANAGER     | 授权课程组织                         | 组织信息，不能改成绩                     |
| ADMIN              | 账户组织与系统元信息                 | 管理用户、班级、任务，默认不读取学生答案 |
| PLATFORM_OPERATOR  | 任务与健康元信息                     | 重试任务，不能读学生图纸或改成绩         |

所有 API / Server Component 数据入口经过 server session，再检查资源归属。停用账户或 tokenVersion 变化立即失效。题干可被选课学生查看，参考答案默认仅成绩发布后可看。私有自测从不通过管理员身份越权开放。
