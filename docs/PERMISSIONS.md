# 账号、教学组织与评分权限

| 账号                      | 入口和范围                                                         | 人员与教学组织                                                                                                                 | 题库、作业与成绩                                                                           |
| ------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 网站管理员 `SITE_ADMIN`   | `/admin`，固定登录 ID 为 `admin`。从学校管理或选校入口进入一所学校 | 建校、补建独立校管、启停和重置校管。选校后可维护该校师生、课程、开课和班级。维护平台 AI、邮件和备案配置                        | 管理本人题目及选定学校授权范围内的校级作业元数据，分派复核教师。正式复核和私人自测另行授权 |
| 学校管理员 `SCHOOL_ADMIN` | `/school`，学校取自已验证会话                                      | 管理本校教师、学生身份及账号。管理课程和开课，建班、安排联合授课或明确交接，导入成员和交付凭据                                 | 管理本人题库，创建、发布本校作业和分派复核教师。管理页只提供所需的组织及作业元数据         |
| 教师 `TEACHER`            | `/teacher`，本校及本人获授教学班                                   | 在本校开放的开课下建立自己负责的班，维护授权班级和成员，新增或关联学生，按授权重置临时密码。全局姓名、学号、账号状态由校管维护 | 维护本人题库和作业。在已分派的学生和作业范围内查看作答、复核及确认成绩                     |
| 学生 `STUDENT`            | `/student`，独立学生认证域                                         | 同一学校一个学生账号可有多条选课关系                                                                                           | 查看分配给本人的作业、提交作答、查看已公布成绩，管理私有自测、错题和申诉                   |

管理端三个账号类型共用 STAFF 认证域，学生使用 STUDENT 域。用户第一次使用临时密码须改密，学校管理员和教师还须验证邮箱。停校、停用账号、凭据失效以及未完成首次设置分别在服务端检查。存量角色由兼容代码读取，后台创建账号时按四种身份派生角色。

每校可有多个独立校管，管理账号的新增、启停和重置仍只允许网站管理员在明确学校范围、近期验证身份后操作。建校自动创建首位校管，详情页持续提供追加入口；后端拒绝停用最后一个启用的校管（409 `LAST_ACTIVE_SCHOOL_ADMIN`）。前端按钮状态来自服务端同一规则。学校停用期间，网站管理员可补建或启用校管；学校本身仍停用，账号不能借此进入后台。没有启用校管的历史学校不能恢复启用（409 `SCHOOL_ADMIN_REQUIRED`）。普通教师、学生的启停不受校管数量规则影响。

## 两份名单各自管理什么

- 班级详情维护当前的 `Enrollment` 和 `TeachingGrant`。退班只移除指定班的成员关系。增加联合授课教师或交接单个授权均保留其他授课教师。
- 发布产生 `AssignmentRecipient`，记录接收人、来源班级和每人的 `reviewerIds`。管理作业与取得原始作答、正式复核权分别校验。班级交接、退班和归档不重算发布快照。
- 旧作业没有发布快照时继续按原有选课、授课规则判断。交接页显示此类已发布作业的数量。接任教师可能取得旧作业的复核权限。相关班级的快照作业单独计数。
- 题库列表、复制、建新版本、停用均检查题目所有者。平台和学校管理账号只在具备相应授权时操作作业，无法据此浏览其他教师私有题库、私有自测或确认正式成绩。
