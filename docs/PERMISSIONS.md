# 账号与权限矩阵

[返回文档目录](README.md)

权限同时检查账号身份、认证域、学校范围、资源归属和具体授权。前端按钮状态只是提示，保存、提交和敏感操作仍由服务端检查。管理员不会因角色层级自动取得私有作答或正式成绩确认权。

## 四类账号

| 账号                      | 后台与范围                                       | 人员和组织                                                                       | 教学与评分                                                                     |
| ------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `SITE_ADMIN` 网站管理员   | `/admin`；登录 ID 为 `admin`；学校业务须明确选校 | 建校，追加/重置/启停独立校管；选校后管理该校人员、课程、开课与班级；维护平台设置 | 管理本人题目及学校范围内获授权作业元数据、复核分派；正式复核与私人数据另行授权 |
| `SCHOOL_ADMIN` 学校管理员 | `/school`；学校由会话锁定                        | 本校教师/学生身份、课程、开课、班级、授课授权、导入和凭据交付                    | 本人题库、本校作业和复核教师分派；不越校、不维护平台设置                       |
| `TEACHER` 教师            | `/teacher`；本校有效开课及本人获授权班级         | 可在本校有效开课下建自己的班；管理授权班级成员、创建/关联学生及授权临时凭据      | 本人题库和作业；按实际分派查看作答、复核、确认成绩                             |
| `STUDENT` 学生            | `/student`；本人资源                             | 一个账号可参加多个班                                                             | 分配给本人的作业、草稿、提交、已发布成绩、申诉、私有自测和错题                 |

STAFF 域包含网站管理员、学校管理员和教师；STUDENT 域单独认证和会话。管理端用同一密码登录输入框接收登录 ID 或已验证邮箱；学生默认先选学校再用学号登录，也保留邮箱密码/验证码入口。认证和资源访问不能跨域绕过身份限制。新账号都须首次改密；学校管理员和教师还必须验证邮箱，网站管理员及学生邮箱为可选。

用户中心、头像和站内通知仅读写当前认证域的本人数据。公告由教师向授权班级的学生及授课教师发布，学校管理员范围为本校，网站管理员明确选校或全平台。收件人从发布快照读取；原业务链接仍按实际作业、复核及资产权限授权。

| --------------------------- | ------------------------ | -------------------- | -------------------- | ---------------------- |

| 创建班级                    | 指定有效本校教师         | 指定有效本校教师     | 可用开课下只指定自己 | 不可                   |

首次设置、学校停用、账号停用、凭据版本与资源归档均独立检查。新增班级时授课授权还不存在：先验证教师与开课范围，在同一事务创建班级和本人授权。

## 学校多管理员

建校原子创建首位独立校管。可以追加多个账号，但本校至少保留一个 `active=true` 的校管；首次改密/邮箱验证状态不参与此数量统计。

追加、启停校管及恢复学校均锁定同一学校行后重新检查。停用最后一个启用校管返回 `409 LAST_ACTIVE_SCHOOL_ADMIN`；历史学校没有启用校管时，恢复学校返回 `409 SCHOOL_ADMIN_REQUIRED`。网站管理员可在停用学校先补建或启用校管，学校仍保持停用，账号不能借此进入业务后台。

## 当前班级与发布快照

`Enrollment` / `TeachingGrant` 表达当前成员和授课关系。退班只移除该班关系；联合授课或交接保留未明确撤销的其他授权。

新发布作业使用 `AssignmentRecipient` 冻结接收人、来源班级及 `reviewerIds`。管理作业元数据、查看原始作答和正式复核是不同能力。成员变化、交接和归档不重算快照。

`audienceRevision=0` 的历史发布作业仍走旧选课/授课兼容规则。接任教师可能因此取得旧作业权限，不能宣称这类记录已冻结。归属盘点和交接预览分别统计两类作业。

## 几何与文件保护

教师题干、基准轴、单位、投影约定和已有冻结框架由服务端逐项校验。学生可引用蓝色题干点作锚点，不能修改；题目允许时可保存自己新增的换面轴，不能伪造教师所有权。

私有原图和派生图按 owner、用途、业务引用和父资产链授权。学校或平台管理身份不等于任意文件读取权。旧退休组织接口继续返回 410，不恢复缺少学校范围校验的旧旁路。
