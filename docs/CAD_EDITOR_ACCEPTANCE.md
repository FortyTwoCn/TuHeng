# 图衡二维 CAD 编辑器验收

本文记录五区工作区重构时的验收。后续参考操作对齐以及最新完整回归见 [参考操作对齐](CAD_REFERENCE_ALIGNMENT.md)。

独立作图入口为 `/geometry`。新建图纸使用 `tuheng.geometry/3.0.0`，单位为毫米。课程中的题干编辑、学生草稿与正式提交、题目展示和教师复核继续读写同一几何契约。可在独立作图页用「文件 → 导入 JSON」打开[样例图纸](geometry-examples/CAD-V3.json)。

## 使用路径

| 操作 | 可复核的结果 |
| --- | --- |
| 选左侧「直线」，点起点、终点，再点第三点，最后点「完成」 | 第一个落点只确定起点，连续两段在 JSON 中共享中间节点。第一次撤销只退回最后一段。 |
| 取圆心或线端点，在精确输入栏输入 `@30<45` 或 `@20,-5` | 根据本次操作锁定的局部投影坐标系生成位置。数值输入直接作为本步几何依据。 |
| 作半径或对齐标注并覆盖显示文字，随后移动引用节点 | 显示文字单独保存，几何实测值根据最新引用重新计算，评分证据可以区分两者。 |
| 选好边界，点「确认」，点击待修剪段，检查预览并确认 | 完成一次撤销可恢复原图。椭圆与样条的剩余部分分别保存为椭圆弧及经过裁剪的三次曲线参数区间。 |
| 选择闭合区域并指定剖面角度、间距 | 图纸保存边界引用，内孔保持空白。重新加载与导出使用同一套毫米几何。 |
| 用手机点圆心，双指放大，继续点选圆周 | 双指操作只改变相机，第一次确定的圆心保持原位。完成、退一步、撤销、复制、删除和精确输入都可点按。 |
| 教师发布几何题，学生保存草稿并提交，教师打开复核 | 使用既有题目版本与提交快照。服务端校验冻结题干和投影配置，评分运行读取作答证据，教师发布正式成绩。 |

## 工作区和浏览器证据

顶部集中图纸、历史、清空、颜色、线型、线宽、网距和文件操作。左轨直接选择绘图和尺寸命令，右轨直接选择修改命令。底部显示命令步骤、局部坐标以及独立的网格显示、网格捕捉、对象捕捉、追踪和正交状态。中央网格以图纸原点为基准，随相机平移和缩放。默认主题为深色。独立页使用整个视口，嵌入页按容器布局并提供专注编辑。

学生专注作答时，题目区在桌面位于修改工具轨之外，在手机可单独打开。选中对象才出现属性卡，顶部可直接复制、删除、关闭。复制在当前文档中创建新对象。选中对象时顶栏修改共同样式，混合选择显示混合值；空选集时设置后续绘图样式。权限和图层由模型约束。

截图使用登录后的 Next.js 页面拍摄。五种视口分别记录初始空图、输入长度、三段已确认并正在预览下一段、选中线段四种状态。课程作答另有桌面和手机两张。[22 张截图索引](evidence/cad-workspace/README.md)

| 验收动作 | 核对的结果 |
| --- | --- |
| 点左轨直线，再点起点 | 正式文档内尚无线段，画布可显示临时橡皮筋和候选端点。 |
| 依次输入 40 mm、2 cm、30 mm，方向向右、向下、向左 | 读下载的 [JSON](evidence/cad/continuous-line-workspace.json) 核对实际坐标、三段长度及四个节点。输入中移动指针保持已键入的数值。 |
| 按 Esc，撤销，再重做；重载刚下载的 JSON | 未确认段消失，三段保留。撤销一次去除最后一段，重做恢复相同节点引用，重载结果与下载一致。 |
| 锁定长度后靠近其他端点，或拖夹点时精确确认 | 无法同时满足捕捉和精确尺寸时保留输入值。拉伸线段与圆半径期间显示实际预览，确认后进入同一撤销历史。 |
| 手机或横屏平板点取圆心后用双指缩放，再继续画圆 | 相机移动期间图元数不变，重新取点使用原来确定的圆心。宽屏触控设备也使用触摸尺寸。 |
| 教师出题、学生保存草稿、刷新并正式提交，教师打开复核 | 同一个图纸契约贯通业务页面与评分证据，服务端校验受保护题干。复核页面只读。 |

各工具的入口、适用几何、参数与测试见[功能矩阵](CAD_EDITOR_PARITY.md)。实机复核步骤见[触摸验收](CAD_TOUCH_ACCEPTANCE.md)。本轮在浏览器中模拟触摸和笔输入，真实平板、电子笔、掌触及系统软键盘仍待实测。

## 验证命令

使用隔离的 PostgreSQL、Redis、对象存储和测试账号。工作区用例包含实站路由及共用组件夹具。电子笔输入使用浏览器指针事件模拟。

```text
npm run lint
npm test
npm run test:integration
npm run build
npm run test:e2e -- "cad-.*spec" "geometry.*spec" "workspace-.*spec" --workers=3
```

## 本轮执行结果（2026-11-24）

| 检查 | 结果 |
| --- | --- |
| TypeScript 与 ESLint | 两项均以 0 退出。在恢复开发者原有的 Next 类型入口后，再次运行类型检查通过。 |
| 单元测试 | 29 个文件、321 项通过。 |
| 集成测试 | 12 个文件、71 项通过。 |
| 生产构建 | Next.js 16.4.2 完成 17 个静态页面及动态作图、登录和业务路由构建。一次构建被依赖版本安全提示中断，原命令重试退出 0。 |
| 开发站点 | 已重新启动本机服务，在 `http://localhost:3000/geometry` 实际登录、绘制、下载，导出线段长 40 mm。 |
| CAD、投影与教学浏览器回归 | 最终生产构建下 115 项一起通过，3 个 worker 用时 2.0 分钟。随后单独执行手机和横屏平板的两项纯触摸连续画线测试，2 项均通过。共计 117 项。 |

首轮回归暴露了三个测试依赖旧界面的假设。端点近轴测试现在按实际 SVG 缩放放到距离轴 5 CSS px 的位置。三种 V/H/W 尺寸在打开页面前设置浏览器视口。笔迹测试用同一总开关执行禁用与恢复，并在同一个会话暂停后紧接画第二笔。最终回归继续断言有效线段、真实校正方向、公共节点及各点所属投影面。

1952 个图元的生产路由和双实例夹具已执行缩放与拖动性能测试。双实例夹具的共享节点拖动及双指输入 P95 超过 33 ms 参考值。[性能数据与测量口径](CAD_CORE_PERFORMANCE.md)
