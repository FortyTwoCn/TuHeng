# 几何编辑器架构

GeometryDocument 是输入来源无关的版本化契约，位于 contracts。geometry-core 提供纯 TypeScript 文档事务、几何运算、投影、笔迹拟合、分析和导出。geometry-editor 提供公共 React/SVG 交互，四种编辑器通过 registry 配置。

依赖方向为 geometry-editor → geometry-core → contracts。domain 使用核心的验证与题干组合，在现有事务中保存草稿、不可变作答和批改请求。现有 grading-core 接收结构化几何证据，继续使用原 Provider、队列、教师复核和成绩发布。

学生提交携带完整文档以支持引用题干点。服务端逐项验证冻结题干、视图、投影配置和图层，拒绝修改或删除题干，再使用数据库中的题干对象组成快照。关联不修改坐标。所有修改经公共文档事务校验，撤销包含对象与关联。

照片识别导入是下一轮扩展点。未来识别结果通过同一 GeometryDocument 加载接口进入编辑器，确认后调用现有保存用例。本轮保留图片上传和历史作答流程。

开发按契约与内核、公共交互、教学流程集成、自动化验收四个阶段执行。每阶段记录实际测试结果。

## 使用入口

登录后访问 `/geometry` 进行独立作图和本地 JSON 保存。教师建题页面的“作答方式”可选择四种几何编辑器。学生在对应作业题目下绘图，保存草稿或正式提交。复核页面直接显示作答快照和经过校验的几何批注。

组件 `GeometryEditor` 支持 `value/onChange` 受控模式和 `defaultValue` 非受控模式。`role` 为 teacher 或 student，`readOnly` 控制只读展示。通过 ref 提供 getDocument、exportJSON、exportNarrative、undo、redo 和 fitToContent。外部 value 更新会同步历史基线。

独立编辑器通过真实 Schema 接受自定义稳定视图 ID、图层 ID 和投影配置。作业编辑器额外传入 `problemDocument`，即使题干没有几何对象也锁定老师给定的文档结构；含题干的文档始终保护已有题干对象及其内部关系。后端仍以数据库冻结版本独立校验，客户端参数不作为权限依据。

## 目录与四种编辑器

| 目录                                           | 职责                                                   |
| ---------------------------------------------- | ------------------------------------------------------ |
| `packages/contracts/src/geometry.ts`           | 版本化文档、对象与关系的 Zod Schema                    |
| `packages/geometry-core/src`                   | 投影、几何、拟合、吸附、文档事务、历史、分析与导出     |
| `packages/geometry-editor/src`                 | 公共 React 组件、Pointer Events、SVG、属性面板与虚拟尺 |
| `packages/domain/src`                          | 题目版本、草稿、正式提交与批改证据快照                 |
| `packages/grading-core/src`                    | 兼容旧图片请求的结构化几何证据及定位验证               |
| `apps/web/components`、`apps/web/views`        | 教师建题、学生作答、作业详情和复核集成                 |
| `tests/unit`、`tests/integration`、`tests/e2e` | 内核、真实依赖、浏览器回归                             |

| 编辑器     | 坐标与默认行为                                           | 工具                                      |
| ---------- | -------------------------------------------------------- | ----------------------------------------- |
| VHW 面投影 | V=(x,z)、H=(x,-y)、W=(y,z)，显示点名                     | 公共全套工具，点/线段投影关联与偏差分析   |
| 三视图     | 主、俯、侧视图，共用正投影映射，可配置侧向，默认隐藏点名 | 公共全套工具，可见/隐藏边与跨视图对齐分析 |
| 正等轴测   | 默认 210°、330°、90°，三轴等比例，轴参数可配置           | 公共全套工具，轴向吸附，二维轴测图编辑    |
| 斜二等轴   | 正面 x/z 保持比例，深度轴默认 45°、系数 0.5              | 公共全套工具，深度轴参数与轴向吸附        |

公共工具包括点、连接已有点、实/虚线段、无限辅助线、平行/垂直辅助线与有限虚线、圆、圆弧、任意/平行/垂直投影面、选择与框选、移动、复制、删除、属性编辑、撤销/恢复、电子笔拟合与失败回退、虚拟尺、网格/坐标轴/图层显示、缩放平移及适应画布。JSON、确定性中文和当前视图 SVG 使用同一文档。

初始化或升级时执行 `npm install`、`npm run db:generate`、`npm run db:migrate`。新迁移 `202611140001_geometry` 仅增加 nullable JSONB 和版本字段，历史图片数据继续通过原接口读取。

## 阶段验收

- 契约与核心阶段通过投影、引用与循环校验、笔迹、题干保护及历史测试。
- 公共编辑器阶段通过四类型绘图、移动端布局、撤销、导出、电子笔及触控缩放测试。
- 教学集成阶段通过真实数据库的草稿、幂等提交、冻结版本、越权拒绝和现有 Worker 结构化评分测试。
