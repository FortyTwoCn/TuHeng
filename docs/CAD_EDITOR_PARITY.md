## 作图辅助的离线对照

| 操作 | 参考 HTML 的实际表现 | 图衡的操作 |
|---|---|---|
| 斜线垂足、圆的切点 | 用鼠标从另一点画线，靠近垂足和切点时出现标记。确认后的线端落在对应位置，切线与接触半径垂直。 | 直线和无限辅助线显示带中文名称的临时关系。相切显示接触点，对圆和圆弧还画出接触半径。 |
| 特征点水平、垂直对齐 | 指针在斜线端点停留后移到同高或同列，开启对象捕捉时出现虚线，两次提交与端点的对应坐标都相等。本组操作切换追踪开关没有改变结果。 | F11 切换特征点追踪，F8 切换从当前起点出发的正交方向。 |
| 任意斜线平行或垂直方向 | 试过开启和关闭追踪，并掠过线端、线身后沿近似平行方向移动。此手势没有锁到斜线方向。 | 在普通画线中，可直接沿已有直线或其垂直方向取点。数值输入与方向兼容时保留提示。 |
| 快速选捕捉类型 | 右键底栏对象捕捉可生成七项。此次离线保存页中弹层超出上边缘。 | 右键「对象捕捉」或点它旁边的小箭头，鼠标和触屏都能切换七种类型。 |
| 完成、撤销、辅助开关 | 连续线可右键结束，动态长度可用 Enter 确认，Ctrl+Z / Ctrl+Y 可撤销、重做。画布收到 F3 / F8 / F11 后，原页底栏状态没有变化。 | 除了右键和 Enter，图衡提供 F3 对象捕捉、F8 正交、F11 对象捕捉追踪。触屏使用底栏对应按钮。 |

## 源码与使用许可

参考 HTML 和脚本仅在本地解压目录核查。参考包中的 JSZip 3.9.1 与标注 2017-06-03 的 verb 没有随图衡分发。二级菜单的依据为同一菜单实际组装对应命令的调用链。形位公差和粗糙度另有参数对话框；保存的考试页面没有展示这些高级标注的独立教学入口。供应商的在线评分、考试和账号页面不在本矩阵内。

本轮在 geometry-core 显式锁定 JSZip 3.10.2（仓库锁文件中已有此 npm 包），采用 MIT 选项。用于生成图衡自己的图纸包。版权与许可随仓库保留。[上游项目](https://github.com/Stuk/jszip) · [许可声明](third-party/JSZip-MIT.txt)

CAD 求交、捕捉、样条区间裁剪和剖面线计算使用仓库 TypeScript 源码。共用 React 渲染、Zod 契约、Floating UI 和项目原有样式组件。源码与几何例子见[编辑器架构](GEOMETRY_EDITOR_ARCHITECTURE.md)和[正式图纸](geometry-examples/CAD-V3.json)。

| 编辑器直接使用的公共库 | 安装版本 | 使用许可 | 用途及上游 |
| --- | --- | --- | --- |
| jszip | 3.10.2 | MIT | 生成图纸压缩包。[JSZip](https://github.com/Stuk/jszip) |
| react、react-dom | 19.3.1 | MIT | 编辑器组件与 SVG 交互。[React](https://react.dev/) |

## 工作区替换与复用

| 审查项 | 现状及处理 |
| --- | --- |
| 独立页与宿主 | 独立页的标题、1200 px 内容壳和单独的图纸类型表单已移除。教学页使用同一个工作区，题目、题号、作答状态和提交属于宿主。 |
| 重复工具 | 原来的横向 ToolPicker 和 CAD 工具目录分别注册绘图入口。顶栏现在处理样式和历史，绘图与标注进入左轨，修改进入右轨。 |
| 输入所有权 | 当前命令在 workspace reducer 内互斥。视口负责命中、导航与临时预览；浮动数值控件通过活动 CAD 会话提交，键盘监听限定当前实例。 |
| 复用 | 保留 VHW、三视图、轴测与换面的图纸坐标、权限、节点/依赖关系、曲线、切割与填充算法及正式作答证据。 |
| 删除 | ToolPicker、EditorToolbar、CadTools 搜索目录和重复的曲线取点控件退出生产入口。虚线由顶部线型设置和直线命令共同生成。读已冻结的旧题目或提交快照仍使用已有契约校验，生产页面只有当前工作区。 |

## 实际操作与覆盖方式

|场景|桌面操作|触屏操作|检查的数据/图形|自动化证据|
|---|---|---|---|---|
|点、连续实线、虚线、无限辅助线|点选、拖动或输入局部坐标|点按起点终点，完成|首点未提交，连续线段共享端点；原始吸附动作可恢复|workspace-line、cad-session、cad-workflows、cad-interaction、geometry-ux、geometry-repair|
|矩形、正多边形|取两角或输入宽高；选半径/边数|同一参数面板|闭环节点、内接和外切半径|cad-workflows、cad-interaction|
|圆、圆心法圆弧、三点法圆弧|点取圆心或三点，输入半径、方向|点按及精确输入|半径、带符号扫角，共线拒绝|cad-workflows、cad-interaction|
|椭圆、插值样条|长短轴落点或输入；依序选经过点并结束|同一命令加可见完成|椭圆参数，精确三次路径，修剪区间重载|cad-interaction、cad-modify、cad-entities|
|文字、三种方向符号|输入中文并放置，选中编辑|点按工具及详细属性|字符转义、方向、尺寸；导出/重载|cad-annotations、cad-interaction|
|五种尺寸|取点/选择圆，放置标注|通过圆对象点选及确认|线性、对齐、角度、半径、直径实测；显示覆盖文字独立|cad-annotations、cad-workflows、cad-interaction|
|基准、粗糙度、公差框格、公差文本|输入参数、放置和重载|使用同一字段|加工方式、基准格、公差上下槽位、旋转和字高|cad-annotations、cad-entities|
|移动、复制、旋转、镜像|选集、定位基点/目标、确认|点按与数值面板|共享节点的坐标、复制 ID、镜像扫角、撤销|cad-transactions、cad-modify、cad-interaction|
|直线、圆/弧、椭圆、样条修剪|选边界，定删除区段并确认|已模拟手机/横屏平板选择两边界修剪直线|线段为真实剩余片段，椭圆弧及样条保留参数域|cad-modify、cad-modifications|
|直线延伸、倒角、圆角|取边界/端点或两条线保留侧|同一命令可以逐点确定|向前最近交点、切点、距离、半径及退化拒绝|cad-transactions、cad-modify|
|剖面线|内部选区或选择闭环|点按边界和可见确认|孔内为空白，相邻轮廓独立，角度/间距存毫米|cad-region、cad-workflows、cad-entities|
|圆规|量取两点、落针定弧，连续复用开度|可见完成及精确输入|量取 3–4–5，分别在两圆心保存半径 5 的弧|cad-annotations、cad-workflows|
|版式与撤销|详细属性、命令结束、撤销、恢复及文件菜单|DOM 点按、双指、模拟笔迹|历史、导出、再载入，多实例隔离；无临时控件入 JSON|workspace-style、geometry-components、geometry-ux、cad-interaction|

表中“同一命令”表示鼠标、手指和笔共用实现。实际触摸脚本覆盖的工具、分辨率和硬件待测项分别记在[触屏验收](CAD_TOUCH_ACCEPTANCE.md)。复杂图纸性能口径见[性能报告](CAD_CORE_PERFORMANCE.md)。
