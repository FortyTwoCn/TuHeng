# CAD 操作与触屏验收

独立作图入口为 `/geometry`。教师题干、学生作答与教师只读复核使用同一个工作区。学生作答页在专注模式提供题目、评分细则、草稿与提交操作。

| 操作 | 鼠标、键盘 | 手指、电子笔 |
|---|---|---|
| 选择工具 | 点左轨绘图或标注图标，点右轨修改图标。相邻分组里可选另一种圆弧或符号 | 点按相同工具，短屏可滚动工具轨 |
| 连续画线 | 点起点，移动鼠标，键入长度。Tab 可编辑角度，Enter 提交一段后继续。已有起点时按 Esc 断开当前线，等待起点时按 Esc 返回选择。右键或空格结束 | 点起点、连续点选端点。也可点光标附近的长度输入框，点勾确认。底栏有退一步、取消和完成 |
| 精确输入 | 命令栏「精确输入与参数」接受局部投影坐标、相对坐标和极坐标 | 参数面板提供负号、小数点等符号。视图设置可以启用手指偏移光标 |
| 框选与加减选 | 从空白处拖框，向右完整包含，向左交叉。Shift 加选 | 在选择方式中使用两角点框选和显式加选、减选 |
| 缩放和平移 | 滚轮围绕光标缩放，中键拖动平移 | 双指平移缩放时保留已经确定的命令步骤。自由笔迹模式中单指默认导航 |
| 对象属性 | 选中对象后在属性卡顶部复制或删除。输入框中的键盘操作限于该字段 | 点选对象后使用相同动作。展开属性后可输入参数并确认 |
| 文件 | 顶栏文件入口支持导入 JSON、导出 JSON、SVG、PNG、图纸包 | 点文件入口选择格式。作业草稿与正式提交在题目区分别确认 |

## 实机复核步骤

真实 Android、iPad、Apple Pencil、硬件掌触抑制和系统软键盘需要在对应设备上复核。

1. 手机竖屏打开独立作图。选择直线并点起点，点动态长度输入框输入 40，确认。继续画第二、第三段并点「完成」。打开和关闭键盘、旋转过屏幕后，检查输入框、勾选按钮和当前线段仍可见，导出的节点连续。
2. 横屏平板用圆工具指定圆心，两指在画布放大并平移，再点圆周。检查只有一个新圆，原圆心的图纸坐标保持一致。
3. 拖动线段端点或圆的半径夹点，检查实时数值，尝试输入精确值并确认。撤销后检查原几何与引用。
4. 切换电子笔取点和自由手绘，分别画直线、圆和 S 形曲线。落笔后放下另一只手，再移出画布或切到后台，恢复后检查无额外图元或滞留预览。用「恢复原始笔迹」核对原轨迹。
5. 点选、框选、加选、减选和复制，查看撤销后的节点。选择修剪边界，确认选界，点选片段并确认，再撤销。导出 JSON 后导入核对几何与样式。
