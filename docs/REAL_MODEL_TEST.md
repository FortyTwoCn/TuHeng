# 真实视觉模型手工验收（尚未执行）

本次自动化验证不调用付费 API，也没有可用的 `OPENAI_API_KEY` 和已确认的视觉模型配置。现有测试结果不包含真实题目理解或评分效果，不可据此报告批改准确率。

## 准备

1. 从项目根目录安装并启动，按 README 在本地配置 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL`。确认所选模型明确支持 Chat Completions 的 `image_url` 视觉输入。
2. 确认计算机可以访问服务商 API。云环境还需该 API 域名在环境出站白名单中；不要以更换代理或关闭证书校验绕过环境策略。本次环境仅配置了服务商相关域名，未验证任意其他视觉 API 的网络连通性。
3. 准备经授权且已匿名化的真实基础题：题目、教师参考、正确学生作答、典型错误作答、等价作图方法，以及部分模糊/遮挡版本。教师先独立给出逐项评分和可接受误差。程序生成样例只能用于协议冒烟测试。
4. 默认关闭持久化；核查图片中不存在姓名、学号、班级等个人信息。API 服务可能按自身政策保存请求。

## 操作和通过条件

|案例|操作|需要人工核验的结果|
|---|---|---|
|角色核验|分别上传题目、参考、学生图|请求清单角色正确，阶段 A 不含 student；不得误把参考当学生|
|图像预处理|上传倾斜、阴影和白纸截图|边框可靠时矫正，失败完整回退；核对辅助线、虚线、点划线、文字与尺寸未丢失|
|手动调整|输入裁切、四角、90/180/270°|坐标作用于 EXIF 后原图；错误坐标回退；调整后旧报告失效|
|题意和细则|先只运行阶段 A|任务、关键关系、必要结果与特定步骤区分正确；不确定性质有标记；知识点 ID 合理；合计 10|
|教师规则|输入明确细则再分析|模型声明采用教师规则，分配和转换说明符合规则；教师核对后确认|
|正确答案|确认后运行阶段 B|逐项证据对应学生图，分数能复算，仍标记待教师复核|
|典型错误|换成预先标注错误答案|错误定位文字、类别、原因、具体修正步骤与教师证据对应|
|等价方法|用不同辅助步骤的正确答案|不因像素外观或参考答案特定路径扣分|
|模糊和遮挡|只替换学生图|缺证据的项为 null；任意评分项 null 时总分 null；知识点可为证据不足|
|异常 API|临时使用错误模型名或不可用配置|明确显示错误，不产出新分数，不回退 Mock；不要故意提交真实学生数据|
|报告下载|下载 JSON 和 Markdown|逐项与总分一致，图像/模型元数据和复核提示完整|
|结果失效|改教师规则、图片或编辑细则|旧报告不再展示，需重新分析/确认或批改|

同一组图可先勾选“未上传区域使用程序生成样例”测试协议是否接受图片；该结果必须单独标记为合成图测试。查看原始响应、模型使用量和输入哈希，记录版本和必要错误信息，不保存密钥或 base64 图片。
