# AI、邮件与网站配置

[返回文档目录](README.md)

平台设置仅网站管理员可操作。学校管理员和教师使用已配置的服务；业务页面不读取供应商密钥。保存密钥、修改邮件和敏感任务命令要求近期密码验证，授权有效期为 10 分钟。

## AI 中心

入口：`/admin/models`。按“供应商 → 模型 → 模块规则”配置，三者分别有版本。

1. **供应商**：设置 Base URL、协议、加密密钥、超时、总并发和日请求预算。支持 `OPENAI_CHAT_COMPLETIONS` 与 `ANTHROPIC_MESSAGES`。
2. **模型**：填写供应商实际模型 ID，明确文本、图像、结构化输出、温度与 token 参数能力。必要时覆盖协议、Base URL 或相对 endpoint；不能仅凭“兼容接口”推断图像和 JSON Schema 能力。
3. **模块规则**：为 `grading.assignment`（正式作业建议）和 `grading.selftest`（私有自测建议）分别选择模型、输出模式、参数及学校/个人日预算。
4. 保存、检查并启用所需记录。后台提供的模型测试会调用实际服务并可能计费；协议替身测试通过不能证明真实模型准确率。

供应商总并发及预算由 Redis 跨 Worker 共享。无合法配置、能力不符、密钥失效或预算受限时，任务显示相应状态，不生成替代分数。配置变更形成新版本，无需重启；旧运行仍使用创建时的快照。

### 密钥与服务出口

主密钥通过 `TUHENG_SECRET_KEYS` / `TUHENG_SECRET_ACTIVE_KEY` 部署，数据库只保存加密 SecretRecord。接口和页面不返回已保存密钥明文。密钥初始化、轮换和备份见[运行指南](OPERATIONS.md)。

受控内部模型和 SMTP 服务使用精确 `host:port` 出口白名单。服务器仍验证目标地址和协议，不允许通过供应商地址绕过资源与网络限制。

运行时不再回退到 `AI_*` 环境配置。`npm run model:sync` 已停用，旧配置只可通过显式导入工具迁移，详见[旧身份与模型迁移](DATABASE.md#旧身份与模型迁移)。

## AI 任务管理

入口：`/admin/jobs`。列表支持筛选、分页、状态轮询和单条详情，默认响应仅含诊断所需元信息，不暴露原始作答、请求原文或完整模型响应。

| 操作                 | 行为                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| 安全重试原配置       | 要求合法原快照及可用凭据，沿用原题目、作答与模型依据；排队或运行中的任务不可重复触发。 |
| 使用当前配置新建运行 | 重新验证当前配置并新建 run，保留父运行及审计；不覆盖历史建议和教师成绩。               |

两种操作都有近期身份验证与请求幂等校验。没有原快照的旧任务只能新建运行，不能补入当前配置后冒充原配置重试。请求结果未知时先刷新核对，不连续重复提交。

AI 只产出建议。评分契约、整数分、未知值与正式成绩保护见[评分架构](GRADING_ARCHITECTURE.md)。

## 邮件服务

入口：`/admin/settings/mail`（系统设置 → 邮件服务）。配置 SMTP 主机、端口、安全方式、认证、发件名称/地址、超时与发送限额。

以下是四个独立动作：

1. **保存新版本**：保存配置，密码留空时沿用明确选中来源版本的凭据。
2. **测试连接**：验证该已保存版本的连接、TLS 和认证。
3. **发送测试邮件**：验证 SMTP 接受邮件；不等同于收件箱已经送达。
4. **启用版本**：切换实际使用版本；与其他管理员并发操作冲突时返回明确反馈。

配置不会在管理员首次登录时强制弹出。管理员首次改密后可直接进入后台，个人邮箱可自愿绑定；学校管理员和教师仍必须验证邮箱。验证码有效期 5 分钟、最多失败 5 次、重发间隔 60 秒，并受账号、网络和平台发送预算限制。

连接失败、认证失败、证书问题和发送状态未知应分别排查；不能通过关闭 TLS 校验解决。没有真实 SMTP 的自动化测试只使用本地协议替身，不宣称外部邮件已送达。

## 网站信息

入口：`/admin/settings/site`（系统设置 → 网站信息）。备案号按单行纯文本保存，最多 120 字符，留空则隐藏。所有页面共用根布局页脚；保存页面刷新页脚，其他页面重新加载后读取当前值。

配置以 `SiteConfigurationVersion` 追加版本并审计，并发旧版本保存返回冲突且保留草稿。公开读取接口 `/api/settings/site` 仅返回备案信息及版本，不返回 SMTP、密钥或账号信息。数据库暂不可用时，页脚读取失败不会阻断登录页。
