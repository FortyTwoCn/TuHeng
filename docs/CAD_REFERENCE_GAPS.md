## 对实际作图影响最大的差异

1. **落点。** 图衡已能预览平行、垂直、相切。差距在于连续追踪多个端点、沿斜边延长找交会、用右下 45° 传宽线作交点参考，以及把已起笔线段的终点直接贴在普通轮廓位置。
2. **作公切线。** 已知起点向圆引切线已有。未指定任何接触点时，原包还能在一侧圆上提示两个圆的公切首点。圆、两种圆弧、样条和正多边形也支持在取点时用正交锁向，图衡的严格正交只覆盖线段、无限辅助线、移动和复制。
3. **整理轮廓。** 差距包括框一次修剪多段、保留同一批边界反复剪/延、指针实时决定倒角或圆角大小、用半圆衔接两条平行线、按交叉线分开的局部区域填剖面。
4. **标尺寸和视向。** 原包可点两条线选角区、靠放置位置选线性标注方向、给方向箭头带字母，并把公差和上下偏差直接存到普通尺寸对象。图衡已有同名绘图大类，上述细操作仍有差距。
5. **反复作图。** 右键重启上个命令、历史一次跳多步、旋转和圆规的光标旁输入、快速盖圆规短弧、记住弧与箭头子工具，都能省掉再次进工具栏的步骤。
6. **出题与对照。** 原引擎还支持分别编辑标准答案图和题干、从标准图派生题干，以及把漏画的几何叠在作答上。图衡的结构化作答、高亮复核和教师确认成绩已存在，标准图派生与缺失几何叠加是另两条还没有的流程。

**公切实测的适用条件。** 在原页用半径 70、35 CSS px，圆心相距 172 CSS px 的两个圆作图，起点、终点各故意偏 3 CSS px。从缓存给出首点候选的圆出发，内、外公切线的两端距理论接触点均小于 0.008 图纸单位。反向操作时首点误差为 2.0–2.7 图纸单位。等半径样本验证了内公切，未从缓存取得外公切。水平等半径圆的顶部接触点同时是象限点，不能单独证明外公切。圆弧会按实际角域筛选候选，靠近弧端还会遇到候选优先级问题。图衡已知首点的单圆切线不受这一对照结论影响。

常规七类捕捉、画线中的平行/垂直/相切标记、图纸网格、正交、中键平移、滚轮围绕光标缩放、双向框选、删除、复制、移动、旋转、镜像和清空均有图衡入口。参考镜头的倍率范围与图衡的适合图纸基准不同，未以倍率数字推断谁能看见更大范围。原页复制一次后再点另一落点，图元计数仍为 2，没有证据证明它可沿同一基点连续放置多个副本。原菜单的矩形和正多边形都会产出多条正式线段；可读取 `regular_polygon` 不是该菜单必然产生可整组选取对象的证据。原圆角还有线圆/圆圆数学函数，学生交互只收两条直线，未列为图衡缺口。

## 可重做的三组对照

- **传宽交点。** 在普通三视图画一条能穿过右下 45° 参考线的水平线，关闭网格捕捉和正交，打开对象捕捉，在理论交点附近偏开少许落点。读导出端点，同时核对候选来源，以排除网格、象限或临时横纵对齐。
- **局部剖面。** 画一个圆和一条穿过圆心且两端伸出圆外的直线。点上半圆填剖面，再查看导出的边界或剖面端点是否跨过直径。只看“剖面填充”按钮不能区分这两种结果。
- **平行圆角。** 画两条相距 40 图纸单位的平行线段，选择靠同一端的两个线身接圆角。查看正式文档是否生成与两条线都相接的 R20 半圆，或命令是否明确拒绝。
