# CAD 参考操作对齐

本次基于 [离线参考包审计](CAD_REFERENCE_GAPS.md)和当前工作树，将实际操作补进同一个图衡 CAD 工作区。独立作图、出题、作答和复核使用共同的几何契约与渲染。工作区交互仍按图衡的题干权限和文档历史执行。

## 作图

- VHW 和三视图的坐标原点右下有 45° 传宽线。开启对象和参考轴捕捉时，可吸附到它与纸面直线的实际交点。来自另一视图的直线可提供位置参考。
- 开启追踪（F11），先后在两个特征点各停留约 400 ms。作图时可捕捉其水平、垂直或斜线延长引导线的交点。方位、距离和屏幕阈值用现有纸面转换计算。
- 已有端点、交点、垂足等候选优先。开启“轮廓就近点”后，可在非特征位置贴上线身、圆弧、椭圆和样条。两圆或圆弧有内公切或外公切解时，直线工具提示第一个接触点，随后可吸附到对应的第二个真实切点。圆弧候选受实际角域限制。
- 正交可用于圆、圆弧、样条、正多边形、线性/对齐标注和方向箭头。圆心圆弧用圆心作两次正交取点的基准，默认逆时针，可选顺时针和劣弧。椭圆可先取短轴。样条取两点后完成会生成线段，三点以上用二次 B 样条插值。
- 连续线仍可就地输入长度、角度。旋转取中心后可就地输入角度，圆规量取时可直接输入开度。圆规取到开度和新圆心后，指向要画的位置并右键（或先点方向再完成）即可盖出短弧。按需要另点起止方向可画指定区间。

## 修改与标注

- 选边界并完成，再点待删区段。可在空白处点两个相对角，把框内的多个区段一起写入一笔修剪事务。确认后可沿同一组边界继续修剪或延伸。完成、右键和空格用于推进或结束画布上的活动命令。
- 倒角和圆角留空时由取点控制大小，精确字段仍可输入距离或半径。两条平行线可以用半间距为半径的半圆接合。零值接角可将原边延至共用节点。
- 点击剖面的局部区域。从线与曲线的真实交点划分边界，记录选中区域用到的边和区间。圆加直径可只填一个半圆。支持孔洞以及按图纸坐标重画。重合边或无法构成闭合区域会提示。若编辑源对象使已保存的边界区间断开，绘图区显示失效提示。
- 线性尺寸随放置位置选横向或纵向。角度标注可点两条线身后选择角区，也可通过三点明确测量。普通尺寸可保存代号、上下偏差和各自显示开关。半径、直径标注有内外引线和圆弧延长图示。
- 方向符号保存向视字母，普通箭头支持第二点定向和定长。引线接触点、字母位置和箭端支持独立编辑。工程标注可从边上引出，含粗糙度加工设置与最多三行的形位公差框。选择模式可双击文字、尺寸或工程符号直接展开属性。

## 使用与保存

空闲时右键可重复上一条绘图或修改命令。从顶部历史菜单可一次撤销或恢复多步。圆弧和向视符号的分组记住上一次选择。网距支持直接输入并随图纸保存，底栏坐标显示到小数点后四位。有限几何可采用辅助显示样式。图纸包 ZIP 可以从文件菜单直接重开，里面的 `drawing.json` 是几何来源。另可导出当前镜头的 PNG，整张图纸导出仍适用。

新增属性与区间使用 `tuheng.geometry/3.0.0` 的可选字段。已有图纸和旧电子笔三次 Hermite 样条仍按原插值方式读取。作用于外观的辅助样式与业务图层权限各自校验。显示文字、公差值和正式测量值分别保存。业务继续通过既有数据库 JSON 列保存正式文档。

## 可复跑用例

- [几何与保存测试](../tests/unit/cad-reference-alignment.test.ts)覆盖多基点、传宽线、公切、框切、半圆接合、半圆剖面、镜像、ZIP、尺寸公差、字母夹点、样条和多行公差。
- [浏览器实际操作](../tests/e2e/cad-reference-alignment.spec.ts)覆盖特征点停留后的交会、传宽交点、框切、局部剖面 ZIP 往返、选补角及双击编辑公差、圆心圆弧的正交与扫掠、两圆公切的两个触点、右键重复与历史跳转、光标旁角度输入。
- [既有交互回归](CAD_EDITOR_ACCEPTANCE.md)给出了正式作图路由、手机与平板尺寸、笔迹、题干保护和评分证据入口。本轮的触控验证使用 Chromium 模拟。实体 iPad 和电子笔尚未验证。
- 参考附件中缺少轴孔标准公差表。图衡保存所录入的代号和偏差。教师双图出题与参考考试引擎的判卷、对照输出属于尚未对齐的宿主流程。
